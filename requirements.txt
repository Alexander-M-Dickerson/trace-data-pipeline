# TRACE Data Pipeline - Python Requirements
#
# Stages 0 and 1 run on the WRDS Cloud and install this file:
#     python -m pip install -r requirements.txt
# The 2026-09-21 production run used Python 3.14.5 there.
#
# Stages 2, 3 and 4 run on your own computer and install requirements-local.txt, which
# includes this file, and then PyBondLab. That file says how.

# Core data processing
pandas>=2.2.3
numpy>=2.0
pyarrow>=20.0.0
# Not installed on Python 3.14, which the WRDS Cloud runs, so the WRDS stages stay as they were
# run (stage 1 falls back to plain Python without it). Stages 2-4 need it on every Python
# version, and requirements-local.txt installs it.
numba>=0.60; python_version<"3.14"

# WRDS database access
wrds>=3.3.0
# `wrds` installs SQLAlchemy itself, but stage0/_wrds_pool.py imports it DIRECTLY to
# recognise a dropped connection, so it is named here rather than relied on transitively.
# (psycopg2 is imported the same way but is guarded by a try/except, so it stays optional.)
SQLAlchemy>=2.0

# Market calendars (Stage 0)
pandas-market-calendars>=5.1.1

# Progress bars
tqdm

# Bond analytics (Stage 1)
QuantLib>=1.36
joblib>=1.4

# Excel/Google Sheets reading (Stage 1)
openpyxl

# HTTP requests (Stages 1-2 - for downloading external data)
requests

# --- Stage 2: monthly panel -------------------------------------------------
# Stage 2 runs on your own machine, not the WRDS grid.

# The Stage 2 engine. Every step is DuckDB SQL; nothing in Stage 2 runs without it.
duckdb>=1.5.0

# PyBondLab (the BBW factors in steps/step3_bbw.py, and every sort in Stages 3 and 4) is not
# listed here: see requirements-local.txt.

# Statistics: the illiquidity kernels (norm.ppf) and the report's Newey-West regressions.
scipy>=1.11
statsmodels>=0.14

# Plotting -- required for the Stage 0/1/2 data reports, not optional if you build them.
matplotlib>=3.8.0

# Stage 2 logs memory headroom when this is installed. Stage 3 needs it for two things
# that are not optional in practice: sizing DuckDB's memory limit against free RAM in the
# data appendix, and recording each grid worker's peak RSS. Without it Stage 3 falls back
# to a conservative fixed limit and records a peak of 0.0, which reads as "measured zero"
# rather than "not measured".
psutil>=5.9

# --- Stage 3: sorts, uncertainty grids, and the paper's exhibits -------------

# required.
